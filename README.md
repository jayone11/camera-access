# Camera Access
A small browser demo that streams your webcam to the page with JavaScript and the getUserMedia API.

## How to use
- Click **Stream** to allow camera access and show the live video.
- Click **Stop Stream** to turn the camera off.

## Run it
Open index.html in a modern browser and allow camera access. Some browsers only allow the camera over https or localhost, so serving the folder locally (for example `npx serve .`) works best.

Built with HTML and vanilla JavaScript.
